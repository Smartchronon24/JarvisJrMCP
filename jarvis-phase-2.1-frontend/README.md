# Jarvis Phase 2.1 Frontend

## Overview
Jarvis Phase 2.1 is a web application designed to provide an intuitive user interface for interacting with the Jarvis system. This project is built using HTML, CSS, and JavaScript, and aims to deliver a seamless experience for users.

## Project Structure
```
jarvis-phase-2.1-frontend
├── src
│   ├── js
│   │   ├── main.js        # Main JavaScript entry point
│   │   └── utils.js       # Utility functions
│   ├── css
│   │   └── styles.css     # Application styles
│   └── html
│       └── index.html     # Main HTML document
├── assets
│   └── fonts              # Custom fonts
├── .gitignore             # Git ignore file
├── package.json           # NPM configuration file
└── README.md              # Project documentation
```

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Run `npm install` to install the necessary dependencies.
4. Open `src/html/index.html` in your web browser to view the application.

## Usage
- The application can be interacted with through the UI elements defined in `index.html`.
- JavaScript functionality is handled in `main.js`, while reusable functions can be found in `utils.js`.
- Styles are defined in `styles.css` to ensure a cohesive look and feel.
